# Security Policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems. Use GitHub's private reporting instead:
**Security → Report a vulnerability** on this repository. Include the LithoMask version, steps to reproduce and, if possible, a sample file.
You can expect an acknowledgement within a few days.

LithoMask is a desktop application that reads layout files (`.mop`, GDSII, OASIS) and does not make network connections.
Reports about malformed-file handling (crashes, hangs, excessive memory use) are welcome.
